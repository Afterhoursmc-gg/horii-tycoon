# H0RII Tycoon

A standalone iOS 3D tycoon game where you run a digital company and creator profile.

## Game loop

- Walk the 3D H0RII HQ and Downtown maps.
- Manage cash, likes, followers, projects and daily revenue.
- Publish creator posts.
- Ship projects.
- Hire creators.
- Create and grow a digital creator profile.
- Advance the day and collect company income.
- Save progress locally on the device.

## Open in Xcode

```bash
git clone https://github.com/Afterhoursmc-gg/horii-tycoon.git
cd horii-tycoon
open HoriiTycoon.xcodeproj
```

Choose an iPhone simulator or device, select an Apple Development Team, and run.

## Technical scope

- SwiftUI interface
- SceneKit 3D scene
- Procedural geometry for the first playable build
- No backend or credentials required
- iOS 17+

The first build intentionally uses original procedural geometry. Authored 3D characters, city assets, animations and H0RII CORE synchronization can be added as separate milestones after the standalone game loop is stable.
